## Problem & user

RocketShip PMs need evidence-based prioritization. Juno turns noisy Slack, tickets, and strategy docs into a ranked, cited backlog they can defend.

## Solution overview

**Retrieval strategy:** Hybrid

Juno needs to be able to accurately analyze customer and internal data to make inferences and prioritize. The RAG helps to refer to internal data while the long form helps for focused sessions with user-specific data.

## Retrieval requirements (RAG)

- **Sources:** Support Tickets, escalations, slack, transcripts
- **Chunking / indexing:** Hybrid (Semantic + Keyword)
- **Grounding rule:** Citations for each priority.
- **Freshness:** Last 30 days

## Requirements

| # | Requirement | Priority | Acceptance criteria |
|---|---|---|---|
| 1 | Retrieval quality and latency | Must | Top-K = 5. Hybrid retrieval. p95 <2s for prioritization |
| 2 | Fail-safe on empty retrieval | Must | Empty retrieval -> flag "insufficient evidence", escalate |
| 3 | Grounded trust | Must | Citations for each priority. |

## Out of scope

Decisions that cannot be cited to a source in the knowledge base. Anything Juno is not allowed to retrieve or act on without a human.
