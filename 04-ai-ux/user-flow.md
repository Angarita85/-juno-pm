# AI-Native User Flow · Juno

_Module 4. Generated by `M4 - AI User Flow Architect.html`. Paste over `04-ai-ux/user-flow.md`._

## Entry point

**Signal type:** New message / transcript received

A new message or transcript is received via the raw input column

**What they see instantly**

'Juno is analyzing the most recent transcript and will provide a perspective.'

## The flow

1. 1/ Juno analyzes the text 2/ Juno uses the RAG to determine guardrails 3/ Juno extracts insights 4/ Juno provides prioritized features based on the new transcript and the guardrails
2. 'Analyzing text' 'Running guardrails' 'Extracting insights' 'Drafting priorities'

## AI moments

**Placement:** Full-Page Canvas

P0 to P3 prioritized feature list in the insights column with the citations justifying the synopsis of the feature as well as why it was prioritized as such.

The user can analyze many transcripts or unstructured feedback quickly and get a logical perspective in terms of priorities versus having leadership drive prioritization.

## Fallbacks

**Kill switch**

The PM can reshuffle the priorities which allows PM to escalate certain features

**Training signal**

Manual promote, gets logged as strategic alignment corrections to improve future prioritization

**Fail-safe**

Juno should be transparent and let the user know that it is missing critical data. it should ask the user to input necessary context to be able to function properly
