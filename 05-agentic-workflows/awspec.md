## Goal

Triage customer complaints and resolve ones that can easily be fixed; escalate ones that need human to review.

**Primary actor:** Human + Agent co-pilot

## Trigger

Agent activates for any customer ticket that has been open longer than 10 min. 

## Steps & tools

**Pattern:** ReAct (single-agent reason-act-observe loop)

| Step | Action | Tool / model | Guardrail |
|---|---|---|---|
| 1 | Read thread 2. Identify problem statement 3. Triage root cause 4. Score risk 5. Escalate OR Propose solutions to customer. | jira | Agent can read operations handbook + slack threads. Can write to customer. Cannot edit workday. |
| 2 | _ | slack.read_thread:read-only |  |

**Schemas**

corpus.retrieve->{chunks:[{text,source,score}]}.

**Memory (in or out of scope)**

- **Episodic:** In-scope, customer ticket context and conversation.
- **Semantic:** In-scope, recent customer interactions metadata, same customer unresolved tickets. Out of scope, do not persist closed/resolved customer tickets. 
- **Working:** In-scope, current thread, customer ID, resolved tickets, retrieved KB chunks. 
- **External:** Strategy KB, slack thread api

## Human-in-the-loop

PM approves any request that requires validated refunds or damages. PM reviews when confidence is <80%.

## Success & failure

- **Done when:** failure, escalation, timeout, confidence < 80%
- **Fails safe when:** Agent can read operations handbook + slack threads. Can write to customer. Cannot edit workday.
